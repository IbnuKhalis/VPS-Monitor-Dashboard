### ✅ [Penyelesaian Temuan 3] — Purpose-Gate R-32: Physical Keyboard PIN Entry
- **Tindakan**:
  - Menambahkan event listener `@keydown.window="handleKeydown($event)"` pada container Alpine.js.
  - Mengimplementasikan fungsi `handleKeydown(e)` yang menangani:
    - Angka `0` sampai `9`: Menambahkan digit PIN secara instan.
    - Tombol `Backspace`: Menghapus satu digit PIN ke belakang.
    - Tombol `Escape`: Mengosongkan input PIN (*clear*).
    - Tombol `Enter`: Memicu pengiriman verifikasi PIN (*submit*).
- **Hasil**: Pengguna komputer/laptop kini dapat langsung mengetikkan PIN dari tombol fisik keyboard/numpad tanpa harus mengeklik tombol virtual di layar. Status: **PASS**.
